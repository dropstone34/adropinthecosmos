# A Drop in the Cosmos

A cosmic, terminal-inspired portfolio built with **Next.js 16**, **TypeScript**, **Tailwind CSS v4**, **GSAP**, and **Framer Motion**.

## ✨ Features

- Interactive constellation graph navigation
- Animated boot sequence & terminal interface
- Desktop + mobile responsive experiences
- NASA APOD integration
- Lichess live game feed
- SEO-optimised with sitemap, robots.txt, and web manifest

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 🛠 Tech Stack

| Layer | Tech |
|---|---|
| Framework | Next.js 16 (App Router) |
| Language | TypeScript 5 |
| Styling | Tailwind CSS v4 |
| Animation | GSAP 3 + Framer Motion 13 |
| Graph | D3 Force |
| Smooth scroll | Lenis |
| MDX | next-mdx-remote |

## 📁 Project Structure

```
app/          → Next.js App Router pages & API routes
components/   → UI components (Terminal, ConstellationPanel, StarField, …)
data/         → Node definitions, boot sequence, commands
public/       → Static assets & web manifest
```
